# API Reference

Full interactive (Swagger/OpenAPI) documentation is auto-generated by
FastAPI and served at:

- **Swagger UI:** `{BACKEND_URL}/docs`
- **ReDoc:** `{BACKEND_URL}/redoc`
- **Raw OpenAPI JSON:** `{BACKEND_URL}/openapi.json`

Every endpoint below already has request/response schemas, example
payloads, and auth requirements defined there via Pydantic — this page
is a quick-reference index, not a duplicate of it.

## Authentication (`/api/v1/auth`)
| Method | Path | Auth | Description |
|---|---|---|---|
| POST | `/auth/register` | none | Create a user |
| POST | `/auth/login` | none | Exchange credentials for access + refresh tokens |
| POST | `/auth/refresh` | none | Exchange a refresh token for a new access token |
| GET | `/auth/me` | bearer | Current user's profile |

## Documents (`/api/v1/documents`)

|---|---|---|---|

## Chat / Retrieval (`/api/v1/chat`)
| Method | Path | Auth | Description |
|---|---|---|---|
| POST | `/chat/conversations` | bearer | Start a conversation |
| GET | `/chat/conversations` | bearer | List my conversations |
| GET | `/chat/conversations/{id}` | bearer | Conversation + full message history |
| DELETE | `/chat/conversations/{id}` | bearer | Delete a conversation |
| POST | `/chat/conversations/{id}/messages` | bearer | Ask a question — **streams** the answer as Server-Sent Events (hybrid retrieval + RRF + re-ranking happen here) |

### Streaming response format
`text/event-stream`, one JSON frame per `data:` line:

```
data: {"type":"token","text":"Revenue ","citations":[],"metadata":{}}
data: {"type":"token","text":"grew ","citations":[],"metadata":{}}
data: {"type":"citations","text":"","citations":[{...}],"metadata":{"retrieval_ms":120,...}}
data: {"type":"done","text":"","citations":[],"metadata":{}}
```
`type` is one of `token | citations | warning | error | done`.
